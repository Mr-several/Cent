# ledger

## 目录职责
- 账本领域模型目录，维护账单、分类与领域类型定义。
- 上层模块会按目录职责组合使用本目录能力。
- 路径：`src/ledger/`

## 文件说明
- `bill.ts`：账单文件，处理账单相关数据或交互逻辑。
- `category.ts`：分类文件，处理分类数据结构与交互逻辑。
- `extra-type.ts`：类型定义文件，约束模块输入输出数据结构。
- `type.ts`：类型定义文件，约束模块输入输出数据结构。
- `utils.ts`：utils 逻辑文件，封装该模块通用处理逻辑。
