# api

## 目录职责
- 数据访问与外部能力封装目录，统一对外部服务的调用方式。
- 上层通常通过统一 API 调用该目录能力。
- 路径：`src/api/`

## 文件说明
- 当前目录没有直接文件，主要通过子目录拆分能力。

## 子目录说明
- `currency/`：币种与汇率能力目录，提供货币数据加载与转换基础。
- `endpoints/`：远端平台适配目录，屏蔽不同同步端点的协议与鉴权差异。
- `ocr/`：OCR 能力目录，负责文字识别调用与结果类型约束。
- `predict/`：预测能力目录，承载规则/算法预测逻辑。
- `storage/`：存储分析与动态策略目录，负责存储层能力编排。
