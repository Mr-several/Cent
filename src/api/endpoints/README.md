# endpoints

## 目录职责
- 远端平台适配目录，屏蔽不同同步端点的协议与鉴权差异。
- 上层通常通过统一 API 调用该目录能力。
- 路径：`src/api/endpoints/`

## 文件说明
- `empty.ts`：空实现兜底文件，用于缺省端点或空能力场景。
- `type.ts`：类型定义文件，约束模块输入输出数据结构。

## 子目录说明
- `gitee/`：Gitee 端点适配目录，处理 Gitee 同步链路调用。
- `github/`：GitHub 端点适配目录，处理 GitHub 同步链路调用。
- `offline/`：离线端点目录，提供本地离线同步适配实现。
- `s3/`：S3 端点适配目录，处理对象存储同步实现。
- `web-dav/`：WebDAV 端点适配目录，处理 WebDAV 同步实现。
