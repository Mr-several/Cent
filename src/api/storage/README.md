# storage

## 目录职责
- 存储分析与动态策略目录，负责存储层能力编排。
- 上层通常通过统一 API 调用该目录能力。
- 路径：`src/api/storage/`

## 文件说明
- `analysis.ts`：分析文件，负责数据分析或统计预处理逻辑。
- `dynamic.ts`：动态策略文件，处理动态配置与运行时策略选择。
- `index.ts`：模块入口文件，负责对外导出公共能力。
- `worker.ts`：Worker 文件，将耗时逻辑下沉到独立线程执行。
