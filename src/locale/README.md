# locale

## 目录职责
- 国际化目录，管理语言资源、Provider 与本地化工具。
- 上层模块会按目录职责组合使用本目录能力。
- 路径：`src/locale/`

## 文件说明
- `index.tsx`：模块入口文件，负责对外导出公共能力。
- `utils.ts`：utils 逻辑文件，封装该模块通用处理逻辑。

## 子目录说明
- `lang/`：多语言文案目录，维护不同语言的文案键值。

## 维护约束
- 保持文档紧凑：优先写职责、调用关系和边界，不贴实现细节。
- 新增、删除、重命名文件或目录后，必须同步更新本 README。
- 接口、依赖、数据流变化时，补充影响面说明并更新上层目录 README。
