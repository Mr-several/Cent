# database

## 目录职责
- 本地数据层目录，提供存储、补丁、调度和一致性能力。
- 该目录位于核心链路，变更需关注兼容性与数据一致性。
- 路径：`src/database/`

## 文件说明
- `assets.ts`：assets 逻辑文件，封装该模块通用处理逻辑。
- `id.ts`：id 逻辑文件，封装该模块通用处理逻辑。
- `patch.ts`：补丁文件，处理增量差异合并与修补逻辑。
- `scheduler.ts`：调度文件，管理计划任务执行时序与触发逻辑。
- `sha.ts`：哈希文件，提供内容摘要计算能力。
- `singleton.ts`：单例文件，维护模块级单例实例生命周期。
- `stash.ts`：暂存文件，处理变更暂存与同步中间状态。
- `storage.ts`：存储文件，封装存储读写与持久化逻辑。
