# src

## 目录职责
- 前端源码根目录，负责模块分层、路由装配与运行时入口管理。
- 应用入口会在此装配路由、全局样式与运行时能力，再分发到各业务目录。
- 路径：`src/`

## 文件说明
- `index.css`：全局样式入口，提供基础样式变量与全局样式重置。
- `main.tsx`：应用启动入口，挂载根组件并初始化运行时上下文。
- `route.tsx`：路由配置入口，定义页面路由映射与页面装配关系。
- `sw.ts`：Service Worker 入口，处理离线缓存和更新策略。
- `vite-env.d.ts`：Vite 运行时类型声明，补充构建环境类型定义。

## 子目录说明
- `api/`：数据访问与外部能力封装目录，统一对外部服务的调用方式。
- `assets/`：静态资源目录，集中管理图标、图片与可复用素材。
- `components/`：通用组件目录，沉淀可复用 UI 组件与交互容器。
- `database/`：本地数据层目录，提供存储、补丁、调度和一致性能力。
- `hooks/`：复用 Hook 目录，封装跨页面共享的状态与副作用逻辑。
- `inline/`：内置数据装载目录，提供内嵌预置内容读取能力。
- `layouts/`：布局骨架目录，统一页面框架与弹层布局结构。
- `ledger/`：账本领域模型目录，维护账单、分类与领域类型定义。
- `locale/`：国际化目录，管理语言资源、Provider 与本地化工具。
- `pages/`：页面目录，负责各业务页面的路由落地与模块编排。
- `store/`：状态管理目录，维护全局业务状态与偏好配置。
- `tidal/`：同步核心目录，承载多端同步适配与关键同步流程。
- `utils/`：工具目录，沉淀跨模块复用的纯函数与运行时工具。
