# store

## 目录职责
- 状态管理目录，维护全局业务状态与偏好配置。
- 业务模块通过状态订阅或 action 调用读取该目录能力。
- 路径：`src/store/`

## 文件说明
- `assistant.ts`：assistant 逻辑文件，封装该模块通用处理逻辑。
- `book.ts`：账本文件，处理账本实体与相关业务逻辑。
- `currency.ts`：币种文件，处理币种数据、换算或格式化逻辑。
- `guide.ts`：guide 逻辑文件，封装该模块通用处理逻辑。
- `ledger.ts`：账本域文件，承载账本核心领域逻辑。
- `preference.ts`：preference 逻辑文件，封装该模块通用处理逻辑。
- `receipt.ts`：小票文件，处理小票识别或小票数据相关逻辑。
- `user.ts`：user 逻辑文件，封装该模块通用处理逻辑。
