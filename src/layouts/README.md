# layouts

## 目录职责
- 布局骨架目录，统一页面框架与弹层布局结构。
- 上层模块会按目录职责组合使用本目录能力。
- 路径：`src/layouts/`

## 文件说明
- `main-layout.tsx`：main layout 组件文件，承载界面展示与交互逻辑。
- `popup-layout.tsx`：弹窗文件，处理弹层展示与交互生命周期。
