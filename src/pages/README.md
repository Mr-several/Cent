# pages

## 目录职责
- 页面目录，负责各业务页面的路由落地与模块编排。
- 上层模块会按目录职责组合使用本目录能力。
- 路径：`src/pages/`

## 文件说明
- 当前目录没有直接文件，主要通过子目录拆分能力。

## 子目录说明
- `home/`：首页页面目录，承载首页容器与主视图逻辑。
- `search/`：搜索页面目录，承载筛选与检索结果展示逻辑。
- `stat/`：统计页面目录，承载统计聚合与图表展示入口。
