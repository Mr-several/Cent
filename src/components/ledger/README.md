# ledger

## 目录职责
- 账本视图组件目录，组织账单列表与账本视图单元。
- 页面与容器组件通常直接组合本目录能力。
- 路径：`src/components/ledger/`

## 文件说明
- `batch-edit-form.tsx`：表单文件，处理输入校验与提交流程。
- `batch-edit.tsx`：batch edit 组件文件，承载界面展示与交互逻辑。
- `index.tsx`：模块入口文件，负责对外导出公共能力。
- `item.tsx`：条目组件文件，渲染单项数据并提供局部交互。
- `style.scss`：style 样式文件，定义该模块对应的样式规则。
