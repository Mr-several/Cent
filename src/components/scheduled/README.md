# scheduled

## 目录职责
- 计划任务组件目录，承载计划项配置与展示。
- 页面与容器组件通常直接组合本目录能力。
- 路径：`src/components/scheduled/`

## 文件说明
- `form.tsx`：表单文件，处理输入校验与提交流程。
- `index.tsx`：模块入口文件，负责对外导出公共能力。
- `list-form.tsx`：表单文件，处理输入校验与提交流程。
- `list.tsx`：list 组件文件，承载界面展示与交互逻辑。
- `scheduled-form.tsx`：调度文件，管理计划任务执行时序与触发逻辑。
- `settings-item.tsx`：条目组件文件，渲染单项数据并提供局部交互。
- `type.ts`：类型定义文件，约束模块输入输出数据结构。
