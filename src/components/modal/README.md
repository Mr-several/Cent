# modal

## 目录职责
- 模态组件目录，统一模态弹窗容器与生命周期。
- 页面与容器组件通常直接组合本目录能力。
- 路径：`src/components/modal/`

## 文件说明
- `index.tsx`：模块入口文件，负责对外导出公共能力。
- `loading.tsx`：loading 组件文件，承载界面展示与交互逻辑。
- `prompt.tsx`：提示词文件，维护模型提示词与模板内容。
- `s3.tsx`：s3 组件文件，承载界面展示与交互逻辑。
- `web-dav.tsx`：web dav 组件文件，承载界面展示与交互逻辑。
