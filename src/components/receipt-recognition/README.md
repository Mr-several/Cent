# receipt-recognition

## 目录职责
- 小票识别组件目录，负责识别结果确认与修正交互。
- 页面与容器组件通常直接组合本目录能力。
- 路径：`src/components/receipt-recognition/`

## 文件说明
- `ai-parser.ts`：解析文件，负责输入数据解析与结构化转换。
- `batch-confirmation.tsx`：批量确认组件，集中处理识别结果的批量确认交互。
- `candidate-item.tsx`：候选项组件，展示单条候选结果并提供选择/修正入口。
- `index.tsx`：模块入口文件，负责对外导出公共能力。
- `merchant-memory.ts`：商户文件，处理商户信息缓存或匹配逻辑。
- `panel.tsx`：面板组件文件，组织该模块容器级 UI 与交互。
- `processor.ts`：处理流程文件，串联数据处理步骤与结果输出。
- `prompt.ts`：提示词文件，维护模型提示词与模板内容。
- `types.ts`：类型定义文件，约束模块输入输出数据结构。
