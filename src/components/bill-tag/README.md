## 文件说明
- `index.tsx`：模块入口文件，负责对外导出公共能力。
- `list.tsx`：list 组件文件，承载界面展示与交互逻辑。
- `tag-form.tsx`：表单文件，处理输入校验与提交流程。
- `tag-group-form.tsx`：表单文件，处理输入校验与提交流程。
- `tag-group.tsx`：tag group 组件文件，承载界面展示与交互逻辑。
- `tag.tsx`：tag 组件文件，承载界面展示与交互逻辑。
- `type.ts`：类型定义文件，约束模块输入输出数据结构。
